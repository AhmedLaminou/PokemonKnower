# Caching des Charges (Functional Requirements) - Pokémon Knower

## 1. Project Overview

Pokémon Knower is an AI-powered educational and entertainment platform designed to be the "Ultimate Future Pokédex". It combines classic encyclopedic data with modern AI capabilities like image recognition, generative storytelling, and personalized gamification.

## 2. User Objectives

- **Identify**: Instantly recognize any Pokémon using camera or image upload.
- **Learn**: Access detailed stats, type effectiveness, and evolution chains.
- **Play**: Engage with daily quizzes and earn badges.
- **Experience**: generate unique stories involving favorite Pokémon.

## 3. Functional Requirements

### 3.1 AI Scanner (Core Feature)

- **Input**: Live webcam feed or file upload (Drag & Drop).
- **Processing**:
  - **Tier 1**: Local TensorFlow model for instant detection of Gen 1 Pokémon.
  - **Tier 2**: Fallback to Cloud VLM (Google Gemini/GPT-4o) for low confidence or new generations.
- **Output**: Pokémon name, confidence score, stats, and "Shiny" status detection.

### 3.2 Dynamic Pokédex

- **Search**: Filter by name, type, legendary status, or color.
- **Visualization**: Interactive charts for stats (Speed, Attack, etc.).
- **Evolution**: Visual graph of evolution paths.

### 3.3 Gamification & User System

- **Accounts**: Secure login via Magic Link or Google (Stytch).
- **Progression**: Users earn XP for scans and quizzes.
- **Leaderboard**: Global ranking based on total XP.
- **Badges**: Unlockable achievements (e.g., "Week Warrior", "Collector").

### 3.4 AI Features

- **Trivia Quiz**: Infinite unique questions generated by LLM based on difficulty.
- **Power Story**: Generates short stories featuring selected Pokémon.

## 4. Non-Functional Requirements

- **Mobile Responsiveness**: UI must adapt to mobile screens (vertical) and desktop (horizontal).
- **Performance**: Local inference should take <500ms.
- **Aesthetics**: "Netflix-style" dark mode, premium animations, glassmorphism.

## 5. Future Roadmap

- **Voice Assistant**: Conversational AI to answer natural language questions (e.g., "What is Pikachu's weakness?").
- **Team Builder**: Competitive team analysis tool.
